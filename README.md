# 西班牙语动词变位 —— 听觉主导学习工具 🎧

基于 Windows SAPI 双语音引擎的西班牙语动词变位听觉学习工具，支持中西双语自动切换朗读，14 个核心动词覆盖规则与不规则变位，提供 2 种学习模式（浏览 + 测验），外加语音设置。

## 📚 教材来源

本项目基于 **Sharplingo 西班牙语课程**，完整课程请访问：

> 🔗 [Sharplingo 西班牙语动词变位课程](https://sharplingo.cn/courses/show-lecture/663f25e1b826335d890c83e9/663f31c9e9ed5f0015269cb1/663f31c9e9ed5f0015269caf)

## ✨ 功能特色

| 模式 | 说明 |
|------|------|
| **1. 浏览模式** | 逐个动词浏览，听+看 6 种人称变位，支持乱序朗读（4 种子模式） |
| **2. 测验模式** | 听变位读音，回答动词原形 + 主语人称（可选中文翻译），计分反馈 |

### 乱序朗读子模式

- **西语 + 中文** — 如 `él habla → 他说话`
- **仅西语连读** — 如 `él habla`，无停顿
- **仅西语停顿** — 如 `él … habla`，主语后停顿
- **中文先出** — 如 `他说话 … él habla`，给你反应时间

## 🎓 涵盖动词（14 个）

### 规则 -ar 动词（3 个）
hablar（说话） · cantar（唱） · estudiar（学习）

### 规则 -er 动词（2 个）
comer（吃） · beber（喝）

### 规则 -ir 动词（2 个）
cumplir（完成） · subir（上升）

### 不规则动词（7 个）
ser（是） · estar（处于） · tener（有） · poder（能够） · poner（放） · venir（来） · ir（去）

## 🔧 环境要求

- **Windows** 系统（使用 SAPI 语音引擎）
- **Python 3.x**

### 安装依赖

```bash
pip install pywin32 colorama
```

> 如果未安装 `pywin32`，语音功能将被禁用，仅可查看文字。

## 🚀 使用方法

### 方式一：直接运行

```bash
python learn_spanish_verbs.py
```

### 方式二：双击启动

双击 `启动西班牙语学习.bat`

### 操作说明

程序启动后自动检测中西语音引擎，进入主菜单后按数字键选择模式，各模式内有快捷键提示。

## 🛠 技术要点

- **双引擎自动切换**：检测文本语言，中文用中文语音朗读，西语用西语语音朗读
- **复合主语拆分**：`él/ella/usted` 等复合主语自动拆分为独立条目，每条独立连读
- **乱序 + 随机主语**：支持 4 种乱序朗读策略，测验时从复合主语中随机抽取
- **重音容错**：测验模式接受不带重音的输入（如 `el` 匹配 `él`），同时支持中文代词作答
- **SAPI TTS**：调用 Windows 原生语音 API，无需额外安装语音包
